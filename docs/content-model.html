User tasks

Organize content around getting access, preparing data, managing a launch and resolving a problem. Use audience tags to distinguish client administrators, implementation leads and support analysts. Avoid duplicating the same procedure under every team.

Article schema

Every article has an ID, title, summary, category, audience, owner, reviewed date, next review date, lifecycle state and body. Search uses title, summary, category, audience and body. IDs remain stable when titles change.

Content types

How-to articles explain a task in order. Troubleshooting articles start with symptoms and diagnostic checks. Reference pages define fields or rules. Policies name the decision authority and exceptions. Templates help users produce a consistent output.

Navigation decisions

Use plain labels that match the task. Give each procedure one canonical location. Link to related procedures instead of maintaining duplicate copies. Retired articles remain in the inventory for traceability but are hidden from normal search.
